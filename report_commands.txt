Команды для скриншотов в отчете по Software-Firewall-Prototype

1. Система способна захватывать сетевые пакеты и извлекать из них ключевую информацию (IP, порты, протокол).
   - Запустить захват пакетов: python firewall.py start
   - Во время работы система будет выводить информацию о пакетах, например:
     "Пакет: 192.168.1.100:54321 -> 8.8.8.8:53 (udp) - ACCEPT"
   - Остановить захват (Enter) и просмотреть логи: python firewall.py logs --table network_events --limit 10

2. Система применяет настраиваемые правила фильтрации к каждому пакету и принимает решение о его судьбе (разрешить/заблокировать). Продемонстрировать разных 3 правила.
   - Просмотреть текущие правила: cat rules.json
     (Показать 3 правила: TCP на порт 80 из сети 192.168.1.0/24 - ACCEPT, TCP на порт 22 к 192.168.1.100 - DROP, ICMP - ACCEPT)
   - Запустить захват: python firewall.py start
   - Сгенерировать трафик для тестирования правил:
     - Для правила 1 (ACCEPT): curl http://example.com (TCP порт 80)
     - Для правила 2 (DROP): ssh 192.168.1.100 (TCP порт 22, если доступен)
     - Для правила 3 (ACCEPT): ping 8.8.8.8 (ICMP)
   - Остановить и просмотреть логи: python firewall.py logs --table network_events --limit 20
     (Показать применение разных правил: ACCEPT для HTTP, DROP для SSH, ACCEPT для ICMP)

3. Система ведет подробный журнал (лог) всех сетевых событий с указанием примененного правила. Продемонстрировать лог из файла БД.
   - После захвата пакетов просмотреть логи: python firewall.py logs --table network_events --limit 15
   - Показать структуру логов с полями: timestamp, source_ip, dest_ip, source_port, dest_port, protocol, action, criticality
   - Продемонстрировать логику принятия решений (ACCEPT/DROP) на основе правил

4. Система интегрирована с модулем FIM и оповещает о любых изменениях в конфигурационном файле правил. Продемонстрировать попытку поменять файл конфигурации.
   - Запустить мониторинг: python firewall.py start
   - В другом терминале изменить rules.json (например, добавить комментарий или изменить правило)
   - Подождать 10 секунд (check_interval в FIM)
   - Остановить мониторинг и просмотреть логи: python firewall.py logs --table fim_events --limit 5
     (Показать CRITICAL оповещение: "Файл изменен для rules.json")

5. Система интегрирована с модулем мониторинга процессов и оповещает о подозрительной сетевой активности легитимных процессов.
   - Запустить мониторинг: python firewall.py start
   - Запустить процесс с сетевой активностью (например, браузер, скачивание файла)
   - Остановить мониторинг и просмотреть логи: python firewall.py logs --table process_events --limit 10
     (Показать мониторинг процессов и оповещения о сетевой активности)

6. Все события (сетевые, FIM, процессы) централизованно хранятся в базе данных SQLite, что позволяет проводить комплексный анализ. Продемонстрировать таблицы базы данных.
   - Просмотр структуры БД: sqlite3 firewall.db ".tables"
     (Показать таблицы: network_events, fim_events, process_events, netsec_alerts)
   - Просмотр схемы таблиц:
     sqlite3 firewall.db ".schema network_events"
     sqlite3 firewall.db ".schema fim_events"
     sqlite3 firewall.db ".schema process_events"
     sqlite3 firewall.db ".schema netsec_alerts"
   - Просмотр содержимого таблиц:
     python firewall.py logs --table network_events --limit 5
     python firewall.py logs --table fim_events --limit 5
     python firewall.py logs --table process_events --limit 5
     python firewall.py logs --table netsec_alerts --limit 5

7. Программа имеет консольный интерфейс для управления и мониторинга.
   - Показать справку: python firewall.py --help
   - Демонстрировать основные команды:
     python firewall.py start (запуск системы)
     python firewall.py logs --table network_events --limit 5 (просмотр логов)
     python firewall.py reload (перезагрузка правил)
     python firewall.py netsec-scan (сканирование сети)
     python firewall.py baseline (создание базовой линии)
     python firewall.py compare (сравнение с базовой линией)

Дополнительные команды для комплексной демонстрации:
- Перезагрузка правил без остановки: python firewall.py reload
- Комплексное сканирование сети: python firewall.py netsec-scan
- Создание сетевой базовой линии: python firewall.py baseline
- Сравнение с базовой линией: python firewall.py compare
