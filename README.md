# Гибридная система обнаружения угроз (Hybrid Threat Detection System)

Этот проект представляет собой гибридную систему обнаружения угроз на основе YARA-сканера, FIM и поведенческого анализа на Python. Система интегрирует сигнатурное обнаружение вредоносного ПО (YARA), контроль целостности файлов (FIM), поведенческий анализ процессов и межсетевой экран для создания многоуровневой защиты, способной выявлять как известные, так и неизвестные (zero-day, fileless) угрозы.

## Функционал

### 1. Модуль захвата и анализа сетевого трафика (`network_capture.py`)
- Использует библиотеку Scapy для захвата сетевых пакетов в реальном времени.
- Извлекает ключевые атрибуты пакетов: IP-адрес источника, IP-адрес назначения, протокол (TCP, UDP, ICMP), порт источника, порт назначения.
- Поддерживает фильтрацию пакетов на основе синтаксиса BPF (например, tcp, port 80, host 192.168.1.1).
- Выводит структурированную информацию о каждом проанализированном пакете в консоль и лог-файл.
- Применяет правила фильтрации и логирует события в базу данных.

### 2. Модуль управления правилами фильтрации (`rules_manager.py`)
- Хранит правила фильтрации в виде списка словарей в файле `rules.json`.
- Каждое правило содержит условия (IP-адрес источника/назначения с поддержкой масок или wildcard, порт источника/назначения, протокол) и действие (ACCEPT - разрешить, DROP - заблокировать).
- Реализует последовательную обработку правил: пакет проверяется по каждому правилу сверху вниз до первого совпадения.
- Поддерживает "неявное запрещение" (implicit deny): если пакет не подошел ни под одно правило, ему присваивается действие DROP.
- Позволяет добавлять, удалять и редактировать правила через конфигурационный файл.

### 3. Модуль принятия решений и логирования (`database.py`)
- На основе анализа пакета и списка правил принимает решение: разрешить (ACCEPT) или заблокировать (DROP).
- Генерирует подробные оповещения для каждого пакета, включая атрибуты, примененное правило и итоговое решение.
- Все события записываются в базу данных SQLite в структурированном формате (CSV-подобном) для последующего анализа.
- Поддерживает логирование сетевых событий, событий FIM и событий мониторинга процессов.

### 4. Интеграция с модулем контроля целостности файлов (FIM) (`fim.py`)
- Мониторит директорию с конфигурационным файлом правил межсетевого экрана (`rules.json`).
- Использует хэширование SHA256 для обнаружения несанкционированных изменений.
- При обнаружении изменений генерирует критическое оповещение о возможной компрометации системы безопасности.
- Логирует события FIM в базу данных.

### 5. Модуль YARA-сканера (`yara_scanner.py`)
- Реализует сигнатурное обнаружение вредоносного ПО с помощью YARA.
- Поддерживает компиляцию правил из файлов .yar.
- Выполняет сканирование отдельных файлов и директорий.
- Структурированный вывод результатов с информацией о совпавших правилах.

### 6. Интеграция с модулем мониторинга процессов (`process_monitor.py`)
- Использует библиотеку psutil для мониторинга запущенных процессов.
- Выявляет аномалии, связанные с сетевой активностью (например, высокое использование сети процессами, которые обычно не используют сеть).
- При обнаружении аномалий автоматически запускает YARA-сканирование исполняемого файла процесса.
- Различает известные угрозы (YARA match) и потенциальные неизвестные угрозы (аномалия без YARA match).
- Логирует события процессов и результаты YARA в базу данных.

### 6. Интеграция с NetSec Sentinel (`network_monitor.py`)
- **Комплексное сканирование сети** (`netsec-scan`): Обнаружение скрытых соединений, руткитов и угроз.
- **Анализ паттернов трафика**: Выявление подозрительных портов, необычных соединений, высокочастотных подключений.
- **Базовая линия** (`baseline`): Создание эталонного состояния сети и сохранение в `network_baseline.json`.
- **Сравнение с базовой линией** (`compare`): Сравнение текущего состояния с эталоном для обнаружения аномалий.
- **Мониторинг в реальном времени**: Непрерывное отслеживание новых соединений (доступно через отдельный запуск `network_monitor.py`).
- **Экспорт результатов**: Сохранение отчетов в JSON или HTML формате.
- **Фильтрация соединений**: По типу (TCP/UDP), состоянию, PID, имени процесса, портам.
- **Обнаружение угроз**: Скрытые процессы, сокрытие соединений руткитами, анализ Docker контейнеров.
- Все оповещения NetSec Sentinel записываются в единую таблицу `netsec_alerts` базы данных firewall.

### 7. Модуль хранения данных и централизованного логирования (`database.py`)
- Использует базу данных SQLite для централизованного хранения всех типов событий.
- Содержит отдельные таблицы: `network_events`, `fim_events`, `process_events`, `netsec_alerts`, `yara_events`.
- Реализует функции для записи событий в базу данных и для выборки событий по различным критериям (по времени, по типу события, по уровню угрозы).

### 8. Модуль управления правилами и конфигурацией (`config.json`)
- Конфигурационный файл в формате JSON для настройки системы.
- Позволяет указать пути для FIM мониторинга, файлы правил YARA, уровни логирования, пути к лог-файлам.
- Поддерживает динамическую перезагрузку конфигурации без перезапуска системы.

### 9. Интеграция и вывод информации (`firewall.py`)
- Объединяет все модули в единую программу.
- Реализует консольный интерфейс (CLI) на русском языке для запуска системы, просмотра текущих правил YARA, ручного сканирования, просмотра логов и запроса данных из базы.
- Все оповещения выводятся в консоль и записываются в базу данных с указанием временной метки, типа события и уровня критичности.

## Требования
- Python 3.6+
- Библиотеки: scapy, psutil, yara-python (устанавливаются из `requirements.txt`)

## Установка
1. Клонируйте репозиторий или скачайте файлы проекта.
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Убедитесь, что у вас есть права на захват сетевых пакетов (может потребоваться запуск с sudo на Linux).

## Запуск
### Основные команды firewall.py

#### Запуск межсетевого экрана
```
python firewall.py start
```
Система начнет захват пакетов, мониторинг FIM и процессов. Нажмите Ctrl+C или Enter для остановки.

#### Просмотр логов
```
python firewall.py logs --table network_events --limit 10
```
Доступные таблицы:
- `network_events` - сетевые события (фильтрация пакетов)
- `fim_events` - события контроля целостности файлов
- `process_events` - события мониторинга процессов
- `netsec_alerts` - оповещения NetSec Sentinel
- `yara_events` - результаты YARA сканирования

#### Просмотр правил YARA
```
python firewall.py rules
```

#### Ручное сканирование
```
python firewall.py scan --path /path/to/file_or_directory
```

#### Перезагрузка правил
```
python firewall.py reload
```
Перезагружает правила из `rules.json` без остановки системы.

#### NetSec Sentinel команды

##### Комплексное сканирование сети
```
python firewall.py netsec-scan
```
Запускает полное сканирование сети с обнаружением угроз, анализом паттернов и генерацией оповещений.

##### Создание базовой линии сети
```
python firewall.py baseline
```
Создает эталонное состояние сети и сохраняет в `network_baseline.json` для последующего сравнения.

##### Сравнение с базовой линией
```
python firewall.py compare
```
Сравнивает текущее состояние сети с сохраненной базовой линией и выявляет аномалии.

### Дополнительные возможности NetSec Sentinel
NetSec Sentinel также можно запускать отдельно для расширенного функционала:

#### Быстрое сканирование
```
python network_monitor.py
```

#### Полное сканирование с экспортом
```
sudo python network_monitor.py --scan --export html
```

#### Мониторинг в реальном времени (10 минут)
```
python network_monitor.py --monitor 600
```

#### Фильтрованное сканирование
```
python network_monitor.py --filter-type tcp --filter-port 80 443
```

#### Создание базовой линии отдельно
```
python network_monitor.py --baseline
```

#### Сравнение с базовой линией отдельно
```
python network_monitor.py --compare --verbose
```

## Демонстрация реализованных фич
- **Система способна загружать и компилировать пользовательские правила YARA из файлов.**
- **Система может выполнять как ручное, так и автоматическое (по событию FIM или аномалии процесса) сканирование файлов и директорий.**
- **Система ведет FIM-мониторинг в реальном времени и автоматически сканирует новые или измененные файлы с помощью YARA.**
- **Система интегрирована с модулем мониторинга процессов и автоматически сканирует исполняемые файлы процессов, демонстрирующих аномальное поведение.**
- **Система различает типы угроз: если YARA находит сигнатуру — это "известная угроза"; если YARA не находит сигнатуру, но процесс ведет себя аномально — это "потенциальная неизвестная угроза".**
- **Все данные (файловые события, результаты YARA, телеметрия процессов) централизованно хранятся в базе данных SQLite.**
- **Модуль межсетевого экрана все еще работает.**
- **Программа имеет консольный интерфейс для управления, настройки и просмотра событий.**
- **Захват сетевых пакетов:** Система захватывает пакеты и извлекает ключевую информацию (IP, порты, протокол).
- **Правила фильтрации:** Применяет 3 настраиваемых правила из `rules.json` (например, разрешить TCP на порт 80 из сети 192.168.1.0/24, заблокировать TCP на порт 22 к 192.168.1.100, разрешить ICMP).
- **Логирование:** Ведет подробный журнал всех сетевых событий с указанием примененного правила в базе данных.
- **FIM:** Оповещает о любых изменениях в файлах и автоматически сканирует их YARA.
- **Мониторинг процессов:** Оповещает о подозрительной сетевой активности процессов и сканирует их YARA.
- **NetSec Sentinel:** Обнаруживает скрытые соединения, анализирует паттерны трафика, сравнивает с базовой линией.
- **База данных:** Все события хранятся в SQLite (таблицы: network_events, fim_events, process_events, netsec_alerts, yara_events).
- **CLI на русском:** Интерфейс командной строки полностью на русском языке с новыми командами для YARA.

## Структура проекта
- `firewall.py` - Главный скрипт с CLI (интегрирует все модули).
- `network_capture.py` - Захват и анализ сетевых пакетов.
- `rules_manager.py` - Управление правилами фильтрации.
- `rules.json` - Конфигурационный файл с правилами межсетевого экрана.
- `config.json` - Конфигурационный файл системы (пути FIM, правила YARA, логирование).
- `sample.yar` - Пример правил YARA для тестирования.
- `yara_scanner.py` - Модуль YARA-сканера.
- `database.py` - Работа с базой данных SQLite (таблицы: network_events, fim_events, process_events, netsec_alerts, yara_events).
- `fim.py` - Модуль контроля целостности файлов с интеграцией YARA.
- `process_monitor.py` - Мониторинг процессов с поведенческим анализом и YARA.
- `network_monitor.py` - NetSec Sentinel - продвинутый мониторинг сети и обнаружение угроз.
- `requirements.txt` - Зависимости Python (scapy, psutil, yara-python).
- `TODO.md` - Список задач.
- `firewall.db` - База данных (создается автоматически).
- `network_baseline.json` - Базовая линия сети (создается командой baseline).
